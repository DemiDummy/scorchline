# Scorchline

A fast, acrobatic first-person shooter demo for the browser. Fight up through Kessler Deep, a bore station sunk into
a moon, ride the freight lift up the shaft, and come out on the Rim under a ringed giant. Two guns, three kinds of
Kilnborn, a dash with two charges. A work in progress: the graphics and animation are being pushed loop by loop.

**Play it at https://demidummy.github.io/scorchline/** (desktop browser with a real GPU, mouse and keyboard; Chrome, Edge or Opera GX. The first
load compiles shaders and takes about half a minute).

WASD move, mouse look, Space jump and double jump, Shift dash, Ctrl or C slide, left mouse fire, 1 / 2 weapons,
R reload, F inspect, E use.

This repo only holds the built game. It's published from a private source repo by `tools/release-pages.sh`.
